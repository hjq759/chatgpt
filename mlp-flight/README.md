# 外卖议事厅：用飞行游戏理解 MLP

一个中文三维飞行小游戏，用“朋友们商量要不要点外卖”的比喻，演示多层感知机从输入到输出的计算过程。

## 怎么玩

下载 `index.html`，用现代浏览器打开，然后点击“带着饥饿消息出发”。

- 自动向前飞行，用鼠标或手指拖动、方向键、WASD 或画面中的箭头按钮转向。
- 对准亮色光环，依次经过七个计算节点；没有对准时会停在光环前，调整后就能继续。
- 每过一站会短暂停留，并在右侧显示当前算式、数值变化和生活化解释。
- 点击“看看朋友们的位置”，可以拖动旋转整个网络；再次点击即可回到飞行画面。
- 窄屏会把计算账本排列到画面下方。

## 这个比喻对应什么

| 游戏里的事物 | 神经网络中的含义 |
| --- | --- |
| 饥饿程度 0.80、价格贵的程度 0.40 | 两个输入 |
| 每位朋友在意饥饿和价格的程度 | 输入到隐藏层的权重 |
| 朋友原本就有的倾向，例如懒得做饭 | 偏置 |
| 省钱派、纠结派、怕饿派三位朋友 | 三个隐藏神经元 |
| 本轮只传正向支持，负分归零 | ReLU 激活函数 |
| 每位朋友在群聊中的发言分量 | 隐藏层到输出层的权重 |
| 群聊汇总并转换成点外卖的可能性 | 输出求和与 Sigmoid 激活函数 |

## 完整演示数据

三个朋友先分别计算：

- 省钱派：`0.80 × 0.50 + 0.40 × (−1.00) − 0.10 = −0.10`，激活后为 `0.00`。
- 纠结派：`0.80 × 0.30 + 0.40 × (−0.50) + 0.10 = 0.14`，激活后为 `0.14`。
- 怕饿派：`0.80 × 1.50 + 0.40 × (−0.25) + 0.10 = 1.20`，激活后为 `1.20`。

你在游戏中沿纠结派的路线飞行：

`0.80 → 0.24 → 0.14 → 0.14 → 0.098 → 1.218 → 约 0.772`

群聊最后汇总：

`0.00 × 0.80 + 0.14 × 0.70 + 1.20 × 1.00 − 0.08 = 1.218`

经过 Sigmoid 换算，得到约 **77.2%** 的点外卖概率。

这些都是固定的教学演示参数。中间支持分可以超过 1，最终概率表示模型的输出，不是识别准确率；朋友也只是神经元的比喻。
